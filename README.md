# 血染钟楼 · 线上魔典（自动推进版）

说书人随机抽取或手动指定角色、确认开局，系统按夜晚顺序唤醒玩家、结算能力；给信息时系统列出选项并标出真实答案，由说书人挑选并确认。不想让系统结算、或者要带自制剧本时，开局选手动模式。语音请配合腾讯会议等。

**在线试玩：https://tianheile.cc**（创建房间，把房间号发给朋友）

当前版本：**1.0.1**（2026-11-07），更新记录见 [CHANGELOG.md](CHANGELOG.md)。

<summary>English</summary>

An unofficial, browser-based grimoire for *Blood on the Clocktower* (Chinese UI, Simplified / Traditional). The storyteller draws roles at random and confirms; the server then wakes players in night order, resolves abilities, and offers the storyteller legal answers for information roles. Players join from their phones with a 4-digit room code. Supports Trouble Brewing, Bad Moon Rising and Sects & Violets. Voice chat is not included — use any call app.

```bash
npm install && npm start   # http://localhost:3000
npm test
```

## 启动

```bash
npm install
npm start
```

打开 http://localhost:3000 → “创建房间”，把房间号或邀请链接发给朋友。

## 一局怎么走

1. **准备**：玩家输入房间号和昵称即自动入座（按加入顺序，说书人可前移/后移或打乱）。说书人在桌面左上角的剧本卡选剧本：暗流涌动、黯月初升、梦殒春宵，或者上传 Json（见下面「上传剧本」）；模式默认智能推进，也可以选手动（见下面「手动模式」）。顶栏显示当前剧本；换剧本会清空角色配置、预览和指定的角色。
2. **开局**：按官方人数配比发角色（酒鬼伪装成不在场镇民，自动选恶魔伪装；有占卜师时才分配红鲱鱼，局中途变出占卜师时补上），每人收到自己的角色。
   - 「角色配置」：点角色切换 随机 → 必选 → 排除。男爵随机时只在 7 人及以上出现，设为必选则任何人数都会出现。
   - 指定角色：抽之前鼠标停在座位头像上，旁边就有角色表，直接选，再点一次恢复随机（手机上点座位走菜单）。「随机抽取」只填没指定的座位，再抽也不动已指定的；抽完改过的座位也算指定，带鹅毛笔章，可以「恢复随机」。全部指定完不用再抽。指定的角色占掉自己阵营的名额，配比不对不拦，只在阵营人数上用虚线圈标出来；智能推进至少要有一个恶魔。
   - 「随机抽取」：角色摆到座位上（只有说书人看得到），可悬停头像更换角色、点座位指定红鲱鱼，也可以再点一次重抽；抽好后下方才出现「确认开局」。之后再改角色配置或有人加入，抽的角色作废，指定的留着。
   - 恶魔伪装：抽好后点一格打开选择，可以连选三个，选完自动跳下一格，再点一次恢复随机；在场的角色都标出来。智能推进只能选不在场的善良角色（在场的置灰），指定的后来撞上在场角色时自动换掉；手动模式可以选剧本上任何角色，系统不换。
3. **夜晚**：按官方夜晚顺序依次处理，操作卡和玩家轮到自己时的牌一样，放在圆桌中央「第 N 夜」下面（放不下时整张缩小），被唤醒的座位外圈亮金线；选项是座位的（谁醉酒、替死、传位……）直接点桌上的座位，已定的目标座位带金圈。夜晚走完，天亮前核对也是圆桌中央的一张卡。顺序表是剧本上今晚行动的角色（首夜表只有首夜行动的，只在首夜行动的不进其他夜晚的表）：不在场、死了或今晚不醒的角色也占一格；今晚第一格是空的时候，说书人「假装叫醒」一分钟（到点自动继续，也可以直接点继续），后面的空格直接跳过；卡上勾「本局不再假装」后，这一局之后都不再假装叫醒。7 人以上首夜的爪牙 / 恶魔互认在入夜时直接发出，不占进度条的格子。需要选人的角色在自己手机上点选，选完（包括说书人代选）停在一张结果卡上，说书人点「确认」才叫下一位，还要裁定的不用多点这一下；信息类角色停在「给信息」卡片：
   - 能力正常时只出现合规答案：真相锁定，只挑干扰项（也可直接点桌上的座位），唯一答案时只剩发送；隐士 / 间谍可被当作的身份旁带他们的角色小牌。卡片底部是玩家将看到的式子。
   - 行动者中毒 / 是酒鬼时卡片解锁全部选项，真实答案带「真」；服务端也会拒绝健康角色的错误信息。
   - 小恶魔攻击镇长时，说书人可以让另一名玩家替死；小恶魔自杀且没有红唇女郎接任时，由说书人选接任的爪牙。
   - 说书人可点座位「代入他的视角」，看到该玩家的画面（只读）；玩家掉线时可“代为选择”。
4. **天亮前确认**：夜晚最后停在确认卡，核对今晚死亡、中毒、保护，需要时纠错；按「天亮」公布死讯并直接进入白天。
5. **白天**：玩家点别人座位提名（每人每天一次、每人每天只能被提名一次，座位头像上会盖「已提 / 被提」小章）。提名后倒数 5 分钟，玩家举手赞成或弃权（弃权只有本人和说书人看得到），到点按当前举手结算；说书人可暂停 / 重置倒数。说书人按「立即计票」时先给所有人弹全屏提示，然后从被提名者下一位起顺时针轮流选择：每人 5 秒，轮到你时弹出选票，点了立刻定下、轮到下一位；提前选过的到点按原选择，一直没选的算弃权，走完自动结算。界面显示需要的票数和处决台现状；「结束白天」会先说明将处决谁 / 无人处决再确认。
6. **自动判定**（暗流涌动）：投毒、僧侣保护、士兵免疫、小恶魔杀人与自杀传位、红唇女郎接任、镇长替死、守鸦人、送葬者、贞洁者（死亡后不再触发）、猎手、管家投票限制、圣徒、镇长三人胜利、死亡票消耗、胜负。
7. **黯月初升 / 梦殒春宵**：夜里选人可以带上角色，一局一次的能力可以选择不用；新增信息卡（筑梦师、贤者、钟表匠、神谕者、卖花女孩、城镇公告员、女裁缝）。
   - 自动判定：茶艺师、水手、弄臣、旅店老板、魔鬼代言人的保护，僵怖假死，主谋的额外一天，镜像双子，涡流（镇民信息只能给错的、白天无人处决邪恶胜），驱魔人，莽夫，疯子（恶魔得知他选了谁），普卡、珀、方古、亡骨魔、教父、刺客、女巫、吟游诗人、教授、侍臣、哲学家、舞蛇人、理发师。
   - 说书人在夜里裁定：水手 / 旅店老板谁醉酒、赌徒猜对与否（可登记时）、造谣者的声明是否成真、月之子选中谁、沙巴洛斯反刍谁；白天和平主义者救不救被处决的善良玩家。
   - 系统随机，目前说书人不能改：心上人死后谁醉酒、亡骨魔杀爪牙后毒哪个镇民邻居、祖母的孙子、镜像双子的对手（麻脸巫婆变出的双子当晚配对、互认）。
   - 不自动处理、由说书人手动：博学者 / 艺术家的私下问答（座位菜单「补发信息」）、修补匠随时死亡、畸形秀演员和洗脑师的「疯狂」。数学家的数字系统不知道真相，说书人自己挑；杂耍艺人白天点座位公开猜，系统算好数字，没用系统猜的说书人自己数。月之子、呆瓜死后弹卡选人（说书人可以代选），选完才能入夜；心上人死时说书人选谁醉酒。各角色的完整表现见 `docs/role-behaviors.md`。

8. **积分、MVP、鸡蛋**（数值在 `public/js/score.js`，结算在 `lib/score.js`，按玩家标识存在房间里）：
   - 所在阵营获胜：胜利积分 +1、鸡蛋 +10；失败：鸡蛋 +1。终局演出最后是结算（奖励一枚枚落下，鸡蛋飞进顶栏的鸡蛋数）。上一局的赢家头上戴阵营皇冠（善良蓝冠、邪恶红冠），保留到下一次分出胜负；赢家自己的桌面上零星放烟花，直到开新局。
   - 终局演出播完后 30 秒 MVP 投票：座位右上角的星星，每人一票、可以投自己、说书人也投；所有人投完立即结束。得票最多的当选（平票一起），MVP 次数 +1、鸡蛋 +5，名牌上标 MVP。说书人在投票中按「再来一局」会先确认，按已投的票结算。
   - 第一次进房间送 3 枚鸡蛋。任何时候点别人的座位 →「扔鸡蛋」，蛋飞过去砸在头像上（所有人都看得到，不挡操作）。点顶栏的鸡蛋数看积分榜；准备阶段座位下面标胜利积分和 MVP 次数。
9. **演出**：开局先拉红幕（帷幔落下、两片幕合上、「第 N 局」盖「开局」章、幕布收拢拉开），再翻角色牌；入夜 / 天亮的纸牌出现时背景演日落 / 日出（桌布上太阳沉下、月亮升起、星星出来，天色、小镇窗户、桌布颜色跟着节拍换）。「⋯ → 设置」里有音效开关、音量、烟花、烟花声、新美术（关掉回到旧版画面）。

**手动模式**（`lib/manual.js`、`public/js/manual.js`）：系统不懂规则，只发角色、记状态、传信息，开局后不能切换。
- 夜晚：没有唤醒顺序和结算，圆桌中央一张卡，说书人自己按「天亮」。点座位「叫醒」发选人牌（选几人、要不要选角色、可不可以不选、一句话），玩家手机上弹出和自动局一样的牌，结果只回给说书人，也可以代选或收回；白天也能发。
- 给信息：点桌上的座位、选角色牌，加数字或文字拼成一句，玩家面板显示成式子，提到的座位自动标上角色。点式子里的一项就去掉。
- 贴标记：点座位「贴标记」，列表是在场角色自己的提醒标记加常用标记，也能自己写；只有说书人看得到，不产生效果，点一下取下。
- 玩家看到的角色：任何座位都能设得和魔典上的不一样（酒鬼、疯子和自制的同类角色）。
- 首夜互认：卡上「发送互认和伪装」按魔典上的阵营拼好，按了才发。
- 侧栏「顺序」是夜晚顺序参考，可以勾掉叫过的：Json 排了顺序用 Json 的，否则是官方顺序，没写顺序的自制角色排最后。
- 白天：提名限制、投票、计票时钟、票数门槛、处决台、死亡票照旧，角色规则全部不生效；处决的人默认死亡。胜负由说书人在圆桌中央判，积分、鸡蛋、演出、MVP 照常，赢家按座位的阵营算（座位菜单可以改阵营）。

**上传剧本**（`lib/script.js`）：支持社区通用的 Json（`_meta` 加角色 id 或完整的角色对象）。内置角色和官方角色只认 id 或中文名，用自己的数据；官方角色表在 `lib/official.js`，由 `python tools/gen-official.py` 从官方仓库生成，只写了 id 的角色也有中文名、能力、阵营、夜晚顺序和提醒标记。认不出来的是自制角色，按 Json 里写的名字和能力显示；图片链接不加载，牌面是名字的第一个字。旅行者和传奇角色显示在角色表里，不进随机抽取，可以手动指定给开局前入座的玩家，不支持中途入座和旅行者规则。角色全在内置 72 个之内的 Json 可以选智能推进，其余只能手动。

说书人点座位可以纠错：补发信息、更换角色（会通知该玩家）、设为中毒、指定红鲱鱼、标记死亡 / 复活、立即处决。顶栏「放弃本局」可随时清空本局回到准备阶段（玩家保留）；「说书人链接」可在别的设备上接管主持（不要发给玩家）。

**房间管理**：
- 邀请：「分享房间」卡片是大号房间号 + 二维码（面杀时对着屏幕扫）+ 复制邀请链接。建好房间时自动弹一次，之后点顶栏的房间号再打开，这是唯一入口（准备阶段 PC 上它带「分享房间」字样，手机上只有房间号）；关掉时卡片缩小飞进房间号，房间号弹一下冒一圈金线，让人知道它收在那里。说书人在这里也能复制「换设备主持」的链接。邀请链接带房间实例标识（`?room=1234&r=…`）：房间号过期回收给新房间后，旧链接会提示「那一局已经结束」，不会带着昵称进到陌生人的房间。
- 房间密码：说书人点顶栏的锁设 4 位数字密码，新的人（玩家、观战）要输对才能进，已经在座的直接重连，换设备链接不用输；分享卡上写着密码（只有说书人看得到），玩家看到一把锁。
- 移出：准备阶段座位菜单「移出房间」，被移出的人刷新也回不来；「⋯ → 让移出的人回来」整单解除。
- 换设备 / 换人顶替：座位菜单「换设备」弹出二维码和链接，新设备打开就接过这个座位（积分、皇冠跟着走），原设备退回大厅；再发一次旧链接作废。开局后手机换了浏览器、清了缓存也能回到座位。
- 观战：开局后或满 15 人时加入的人自动观战，只看公开信息、不能发言，准备阶段有空位时圆桌中央有「入座」；桌子右下角的观众席写着名字。
- 解散：「⋯ → 解散房间」所有人退回大厅，存档和聊天记录一起删掉。
- 大厅：字标下一句「快速、简约、精美的线上魔典」，一条加入房间的表单（房间号是连成一个框的四个小方格，从左往右连着打，粘贴带别的字也只留 4 位数字），下面一行说书人建房；页面底部是对局里的小镇。本机去过、还在的房间插成屋顶上的旗子（房号、走到哪、几个人、是说书人还是玩家），点一下回去；手机上旗子排成一行。
- 第一次打开时弹全屏介绍（`public/js/intro.js`）：桌上叠着三张牌，下一页把牌往左丢，上一页拿回来——只讲这本魔典好在哪，不讲玩法：全程自动结算、新手上手快、界面和动画（放一段真实对局）；看过记在本机不再自动弹，大厅右上角「介绍」可以再打开。
- 关于（`public/js/about.js`）：大厅右上角「关于」、对局里「⋯ → 反馈 · 关于」打开。顶上是作者名帖（红名章 + 署名 + 社交账号），下面三页：说明（第一行：免费、非商业的粉丝自制工具，不是官方；开源、免注册、没有语音）、反馈（信纸，寄出盖「已寄出」章）、分享（本站二维码、复制链接，手机上多一个系统分享）。大厅打开在说明页，对局里打开在反馈页。不收打赏：官方社区内容政策不许拿粉丝作品赚钱。署名、名章、社交账号都在 `public/js/author.js` 填，空着的显示成虚线占位。反馈一条一行追加到 `data/feedback.jsonl`（`DATA_DIR` 下；每个 IP 连寄 3 封后每 10 分钟 1 封），带房号、繁简和浏览器。

- 座位不互相压：头像、名牌的大小都按相邻座位的距离算（`board.css` 的 `--c`），座位多、屏幕小时头像缩小，名牌骑到自己头像的下沿上。提名小章和举手标记贴在自己头像上，说书人提示和玩家标记朝圆桌中心挂（`.seat-more`），不把座位顶高，也不占邻座的地方。
- 界面布局：没有底部操作坞。说书人和玩家要看的、要点的都在圆桌中央「第 N 夜 / 天」下面（准备阶段的剧本、人数和开局按钮，天亮、结束白天的按钮，夜晚的操作卡）；提名期间的取消 / 结算 / 计票按钮在审判牌最下面；处决台上有人时说书人的按钮挂在绞刑架下面。进度条是一张纸卡：宽屏竖放在圆桌右边，窄屏（999px 及以下）横放在桌面底下；牌用一根线串起来贴在纸上，两端的双线圆章骑在纸卡边上（夜晚 ☾ → ☀，白天 ☀ → ☾）。走过的线是金线，走到下一张时金线描过去，线到了那张牌被拽一下、抽出来一截、盖上金章。夜晚是今晚的唤醒顺序：玩家只看到剧本的角色顺序，看不到走到哪一张（服务器不发这个位置）；说书人有金线和章，每张牌旁挂着座位号名牌，假装叫醒的是虚线牌；白天是天亮 → 今天的每次提名（被提名者 + 票数名牌，上处决台的红框）→ 讨论 / 正在投票 → 处决台 → 入夜。牌放不下时两端的章不动、中间的牌滑动（竖条先拉长到整列高，手机上牌保持 30px），走到新的一格自动滚到中间。点纸卡弹出完整列表：夜晚是牌和名字，说书人还有座位号、进度和不在场 / 今晚不醒；白天是每次提名的双方和票数；开着时跟着进度更新。代码在 `public/js/progress.js`，样式在 `board.css` 的 `.pg-*`。右侧栏：玩家是「游戏日志 / 聊天 / 角色表」，说书人是「流程 / 游戏日志 / 聊天 / 角色表」；游戏日志只读（说书人可发公告），按轻重排版（阶段分割线、死亡处决重行、琐事淡字、终局横幅），数据来自 `announce()` 的 `e`；聊天左边是一列页签（公共、说书人 / 私聊记录、每个座位），选中哪页就和谁聊，座位菜单和桌上的气泡直接翻到那一页，说书人的公告同时进公共页和日志。未读：聊天标签和页签上的红点带条数，新消息盖章后慢闪三下；私聊在发送者座位旁冒气泡，读了才消失；公共消息在说话的人旁边冒几秒。可点「⇥」收成竖条，标签同样显示未读条数。顶栏只留常用按钮，邀请链接、说书人链接、繁简切换、离开、放弃本局在「⋯」里。
- 快捷键：按钮没有主次，回车不触发任何操作（输入框里回车才算提交）；Esc 关闭菜单 / 弹窗 / 取消代选。
- 玩家左上角面板：角色牌、能力、每晚的信息式子（座位号圆章 + 角色小牌 + 数字 / 恶魔✓✗），可收成只剩角色牌（点牌或「收起」）；中屏（面板浮在桌面上）轮到自己选人时自动收起，不挡座位。新信息飞入并点亮相关座位，点或悬停一条信息也会点亮。
- 轮到自己夜晚行动：圆桌中央一张纸牌，大角色牌 + 行动图标 + 一句话（例如「选择一名玩家，使其「中毒」」，关键词用语义色）。行动之后，自己视角里目标座位上自动标出「中毒 / 保护 / 击杀 / 主人 / 查验」，到第二天白天结束。
- 白天被动能力（猎手开枪、贞洁者、圣徒、红唇女郎、镇长）触发时游戏停下，圆桌中央弹出裁定卡并响一声（提名期间盖在审判牌上，贞洁者被提名时是桌面左上角的小窗，不挡投票）。结果只有一种时（假猎手 / 酒鬼开枪、健康猎手射真恶魔、健康贞洁者被镇民提名……）只有一个按钮；中毒、醉酒、酒鬼就是没有能力，也只有「无效」；只有隐士 / 间谍的登记可选时才二选一，两个按钮没有主次。服务端也拒绝反着选。
- 猎手（含以为自己是猎手的酒鬼）白天在其他活着的人头上有瞄准钮，点开先弹窗讲清规则再开枪；开过一枪后收起。
- 玩家座位标注：说书人信息里提到的角色以小牌贴在相关座位旁，玩家也可以点座位「加备注」（墨色，只存在自己浏览器里，新的一局自动清空）。
- 说书人流程日志按夜 / 天分组，每步一行式子；错误信息红框、登记信息橙框。
- 界面第一次进来默认简体，顶栏可切换繁体（存在本机）。转换表 `public/js/t2s.js` 由 `python tools/gen-t2s.py` 生成（需 `pip install opencc-python-reimplemented`），改了界面文字后重新运行一次。
- 背景（小镇剪影、星空、纸纹）是 `public/img/` 下自己画的 SVG。
- 演出：服务端在关键节点推演出事件（`lib/util.js` 的 `fx`，`state.fx`），客户端 `public/js/fx.js` 排队播放（入夜、天亮叉子刺向夜死者、提名、计票、贞洁者、处决、无人处决、猎手、胜负、翻角色牌、轮到你、自己的行动、说书人魔典上的夜间结算；计票时钟每数过一人滴答一声）。统一是「平涂压暗桌面 + 米白纸牌 + 墨线印章」，不用渐变和发光，冲击感靠一拍一拍落下的节奏、盖章、震屏和音效。公共演出挡住操作、不能跳过，播完为止（开局翻角色牌和「第 N 夜」纸牌例外：点一下或按 Esc / 空格 / 回车跳过）（页面切到后台时直接跳到结尾）；开局翻角色牌时中间亮出能力说明，读完牌飞进左上角面板（面板在这之前空着）；反噬是闪电劈向提名者、射杀是准星加一支箭，夜里死的人天亮时统一盖「死亡」章（不透露死法），只有真正的处决才用绞刑架；射空在说书人裁定后也播全屏（箭擦过去，「未中」章飞到射手身上），射手座位上所有人都看得到「射 N 号失败」；音效在 `public/js/sfx.js`，录音在 `public/sfx`（`tools/sfx-build.py` 生成，来源见 `docs/sfx-sources.md`），入夜钟声现场合成，顶栏喇叭静音。背景音乐在 `public/js/bgm.js`，大厅、白天、夜晚、提名各一首循环；开局前（大厅、房间里等人、一局演完等下一局）一直放大厅那首，跟着演出换：入夜随第一声钟、天亮随天亮音效交叉淡化；提名时鼓和弦乐推起来，印章落下的同一拍提名曲第一个音起，判决章落下时回到白天曲刚才的位置（`tools/bgm-score.py` 渲染自编曲，`tools/bgm-build.py` 统一响度）。顶栏喇叭一键全静音，设置里音效、音乐各有音量和静音。式子和图标在 `public/js/glyph.js`，样式在 `public/css/hud.css`。

## 自己部署

需要 Node.js 18 及以上。房间存在 `data/rooms/`（每个房间一个文件，只写有改动的），重启不丢；旧版本的 `data/rooms.json` 启动时自动拆开，原文件改名为 `rooms.json.migrated`。同时最多 99 个房间，满了先腾 10 分钟没动静的空房（没有真人玩家），其次是 6 小时没动静的房间，都要没人连着；腾不出来就提示房间已满，不会挤掉正在等人或中场休息的房间。

环境变量：`PORT`（默认 3000）、`DATA_DIR`（存档目录，默认 `data/`）、`MAX_ROOMS`（房间上限，默认 99）、`RATE_LIMIT=0`（关掉频率限制，压测用）。`BOTC_DEBUG=1`（测试服用：大厅左上角出现「调试模式」，勾上后建的房间里说书人可以加机器人、随时换成任意座位的身份、离席时由机器人代为主持；正式服不要开）。

- **频率限制**：每个 IP 建房连续 5 个后每分钟 1 个；输错房间号 / 密钥 / 换设备链接连续 10 次后每 3 秒 1 次（猜遍 9000 个房号要七八个小时）；每个座位聊天连续 6 条后每 2 秒 1 条；每个连接每秒 20 个操作。
- **反向代理**：服务器直接收到的连接用对方地址；从本机或内网地址（Caddy、nginx、Docker 端口映射）来的连接取 `X-Forwarded-For` 最后一项当客户端 IP。Caddy 默认会带上；nginx 要加 `proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;`，否则所有人共用一个 IP 的限额。
- **隐私**：聊天（包括私聊）以明文存在服务器的 `data/rooms/` 里，三天没动静或说书人解散房间时删除。公开给别人用的实例，请在页面或群里说明这一点。

- **直接运行**：`npm ci --omit=dev && PORT=3000 npm start`
- **Docker**：
  ```bash
  docker build -t clocktower .
  docker run -d --restart unless-stopped -p 3000:3000 -v clocktower-data:/app/data clocktower
  ```
- **systemd**（Linux 服务器长期运行，崩溃自动重启）：`/etc/systemd/system/clocktower.service`
  ```ini
  [Unit]
  Description=clocktower
  After=network.target

  [Service]
  WorkingDirectory=/home/user/clocktower
  ExecStart=/usr/bin/node server.js
  Environment=PORT=3000
  Restart=always
  User=user

  [Install]
  WantedBy=multi-user.target
  ```
  `sudo systemctl enable --now clocktower`
- **HTTPS**：说书人链接里带着说书人密钥，公开部署建议用域名加 HTTPS。用 [Caddy](https://caddyserver.com/) 最省事，`Caddyfile` 一行：`your.domain.com { reverse_proxy localhost:3000 }`（WebSocket 自动支持），然后防火墙只开 80 / 443。
- **一键搭建新服务器**：复制 `tools/deploy.env.example` 为 `tools/deploy.env` 填上自己的服务器和域名（这个文件不会提交），`bash tools/setup-server.sh` 装好 Node、Caddy（自动 HTTPS）和 systemd 服务并部署。云服务器防火墙要放行 80 / 443，域名 A 记录指向服务器。
- **一键更新**：本地提交后 `bash tools/deploy.sh`：上传当前提交（不碰 `data/`、不传 `art-src/`），先把存档备份成 `data/rooms.before-deploy.tgz`，`package-lock.json` 变了才重装依赖，然后重启 systemd 服务 `clocktower`。重启时进行中的对局会断线几秒，存档不丢。

## 开发

- 规则：`lib/night.js`（夜晚行动）、`lib/rules.js`（死亡/胜负）、`lib/day.js`（提名、计票时钟）、`lib/engine.js`（流程）、`lib/setup.js`（抽角色、指定、预览）、`lib/manual.js`（手动局）、`lib/script.js`（上传的剧本）。
- 角色数据：`public/js/roles.js`，前后端共用。内置剧本：暗流涌动、黯月初升、梦殒春宵（说书人在准备阶段圆桌中央切换；换剧本会清空角色配置和预览）。夜晚顺序取自官方总顺序表。
- 新剧本的规则在 `lib/night.js` 各角色和 `lib/rules.js`（死亡保护与胜负），哪些自动、哪些由说书人裁定见上面「一局怎么走」第 7 条。状态效果统一记在 `g.eff`（中毒 / 醉酒 / 夜里保护 / 处决不死 / 诅咒 / 疯狂），按「第 N 夜 = 2N、第 N 天 = 2N+1」的刻度过期；诺-达鲺的邻居中毒是实时算的。阵营可以和角色不同（`seat.align`：莽夫、舞蛇人、方古；麻脸巫婆、理发师换角色不换阵营）。
- 前端每次收到状态都用 `morph()`（`public/js/ui.js`）做差量更新；聊天按序号增量推送。事件请用 `onclick` 等属性挂（`h()` 的 `on*` 参数），不要用 `addEventListener`。
- 积分 / 鸡蛋 / 演出的前端：`public/js/scores.js`（皇冠、MVP 投票、积分榜）、`egg.js`（扔鸡蛋，事件在 `state.eggs`，不进演出队列）、`fireworks.js`、`settings.js`，样式在 `public/css/party.css`；背景的日夜由 `fx.js` 在入夜 / 天亮演出里按节拍切 `body[data-phase]`（`dusk` 是日落那一拍）。
- 测试：`npm test` 跑全部；也可以单独跑 `node tests/dlc.test.js`（黯月初升 / 梦殒春宵关键规则）、`node tests/score.test.js`（积分、MVP、鸡蛋）、`node tests/rules.test.js`（关键规则）、`node tests/flow.test.js`（登记、替死、传位、计票、管家）、`node tests/ops.test.js`（配置、预览、纠错）、`node tests/room.test.js`（移出、房间密码、换设备、观战、腾房；起一个真服务器测限流、退回大厅、解散、存档、二维码）、`node tests/engine.test.js`（三个剧本各 300 局随机对局）、`node tests/mix.test.js`（用内置角色随机拼剧本的跨剧本对局）、`node tests/script.test.js`（Json 解析）、`node tests/manual.test.js`（手动指定、手动局、相克）。
- 演示页 `/demo.html`：只放对局里不好撞上的场景——提名与投票、白天裁定（猎手 / 贞洁者 / 镇长）、夜晚结算演出、扩展剧本的信息卡、终局与 MVP、新美术素材。开一局就能看到的界面直接在游戏里看（说书人可以「代入」任意座位看玩家视角）。`/phone.html` 把同一个场景放进三种手机尺寸并排看。
- 存档 `data/rooms/房间号.json` 先写临时文件再改名，退出（Ctrl+C、systemd 重启）前把没写完的同步写完；读取失败时会备份成 `房间号.json.bad-时间戳` 而不是悄悄丢掉。三天没动静的房间会被清理。房间管理在 `lib/store.js`（存档、腾房）、`lib/ops.js`（移出、房间密码、换设备、观战）、`lib/limit.js`（频率限制），大厅和邀请在 `public/js/lobby.js`、`invite.js`。
