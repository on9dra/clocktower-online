## Style

- Short, plain UI English. Layout was sized for Chinese, which is much narrower: prefer the shortest natural wording, especially for buttons, tags, menu items, seat labels.
- Buttons and menu items: sentence case ("Start game", "Copy link"). Headings may use Title Case.
- 【角色名】 emphasis brackets: drop the brackets in English, the capitalised character name stands out on its own ("{0} is the Imp"), unless the whole string is only the bracket.
- Chinese punctuation becomes English punctuation. Keep a leading/trailing separator if the Chinese has one (key starting with "，" → value starting with ", ").
- Keep every placeholder {0} {1}… exactly once; reorder them freely for English word order. Placeholders are player names, seat numbers, numbers, or character names.
- Pronoun for a player: "they/them".
- A fragment that has no place in English word order may translate to "" (empty string) — check the code that renders it first.
