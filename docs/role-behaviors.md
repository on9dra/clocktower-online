## 二、通用规则

### 说书人的卡

| 卡 | 何时出现 | 按钮 |
|---|---|---|
| 等待 | 玩家还没选 | 代为选择、跳过 |
| 能力裁定 | 行动者中毒、醉酒，或是酒鬼、疯子 | 只有「无效」 |
| 结果 | 选完人（含代选）且没有后续；无人操作但有结果的步骤 | 确认；选中莽夫时多一行 |
| 选人裁定 | 水手、旅店老板、传位、替死等 | 选一项后确定 |
| 给信息 | 信息类角色 | 发送；能力正常只能发合规信息，失效时可发错误信息，隐士 / 间诜登记的答案标「登记」 |
| 假装叫醒 | 今晚第一格是空的 | 继续，60 秒后自动继续 |
| 天亮前核对 | 整夜走完 | 天亮，公布死讯 |
| 白天裁定 | 猎手、圣徒、红唇女郎、镇长、呆瓜、和平主义者 | 结果唯一时一个按钮；可登记或官方写「可能」时两个 |

死亡的角色默认不醒，例外已在角色表里写明。

### 演出

- **自己的演出：** 三个剧本的选人角色和信息角色都有专属演出（暗流涌动在 `fx-ab.js`，黯月初升、梦殒春宵在 `fx-ab-dlc.js`，不是暗流涌动的房间才下载）。规矩一样：压暗 → 信物从自己的牌里升起 → 这个角色自己的一套 → 答案落在桌心停一会 → 落到对应座位旁边，没有座位的进左上角面板。
- **不演的：** 口头发动的技能（造谣者、杂耍艺人、月之子、呆瓜、博学者、艺术家），只改变配置的（男爵），不知情的（酒鬼、隐士、畸形秀演员、修补匠）。
- **只演出手：** 赌徒、教授、驱魔人、麻脸巫婆和所有恶魔都看不出结果，生死天亮才揭晓；醉酒、中毒的人看到的和真角色一样。舞蛇人没换到时也只演到「查验」，选的不是恶魔和选中恶魔但失效看起来一样。
- **舞蛇人换到恶魔：** 他当场就知道，所以「查验」之后接着演：两张牌绕着彼此游到对方座位，自己的牌翻成恶魔盖「交换」，蛇再咬一口对方盖「中毒」，对方现在的角色落在他座位旁边，最后翻角色牌。
- **目标看到的：** 规则要他知道的才有：被驱魔的恶魔、被洗脑的人、镜像双子、被换角色的人。换角色的东西都从桌心来，不泄露是谁干的（原恶魔看到蛇从桌心游来，牌翻成舞蛇人，盖「中毒」）；方古跳身走接任演出。
- **全桌：** 被诅咒的人提名（咒印炸开）、夜里复活的人（灰牌恢复颜色，盖「复活」）、涡流无人处决（桌心漩涡，接邪恶获胜）。
- **说书人魔典：** 所有角色一拍，用各自的信物；茶艺师、弄臣、水手的被动各演各的，吟游诗人音符飞过全桌。一夜排队超过 3 段就跳过，所以不能只靠看演出确认结果。
